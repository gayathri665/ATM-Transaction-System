# ATM Transaction System

## Overview

This project is a Java AWT-based ATM Transaction System that simulates real-world banking operations through a graphical user interface.

## Features

- PIN Authentication
- Balance Inquiry
- Cash Deposit
- Cash Withdrawal
- Transaction Processing
- Receipt Generation
- Dynamic GUI Navigation
- HashMap-Based Account Management

## Technologies Used

- Java
- Java AWT
- Object-Oriented Programming (OOP)
- HashMap

## Project Description

The application provides a user-friendly ATM interface where users can securely access banking services after PIN verification. The system allows deposits, withdrawals, balance checks, and transaction receipts while demonstrating Java GUI development and OOP concepts.
